# Spa Serenidad

Aplicación Angular para consultar servicios y gestionar reservas de un spa con persistencia local en IndexedDB.

Autora: Lizbeth Cruz Choque — [@lizzy-sys](https://github.com/lizzy-sys). Trabajo individual.

Repositorio: https://github.com/lizzy-sys/spa-reservas-angular

## Instalación

Usar Node.js 24.21 o superior de la rama 24 y npm 11.

```sh
npm ci
npm start
```

Abrir http://localhost:4200. En Windows, si PowerShell bloquea npm, usar `npm.cmd`.

```sh
npm test -- --watch=false
npm run build
```

El proyecto se generó con Angular CLI 22.3, SCSS, sin SSR, sin configuración de IA y con detección zoneless.
